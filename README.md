# the fun, the songs and the words

This repository currently contains data only: courses, lyrics, audio, MV, vocab, and source materials. These files were copied from the previous project so the work can be rebuilt cleanly.

## Folders

- `data/` — course and lyric datasets, vocabulary, and source documents
  - `data/lyric/` — courses, lyric sentences, grammar, exam, textbook, and TEM-4 files
  - `data/source/` — Unit 13 slides, textbook notes, classified exam items, and knowledge export
  - `data/vocab/` — vocabulary spreadsheet
- `public/` — media played with the songs
  - `public/audio/` — song audio
  - `public/mv/` — music videos and poster images
